
# Car Price Prediction using Python

## Project Overview
This project is part of the CodeAlpha Data Science Internship.

The objective is to predict the selling price of used cars using Machine Learning.

## Dataset Features
- Year
- Present_Price
- Kms_Driven
- Fuel_Type
- Seller_Type
- Transmission
- Owner
- Selling_Price

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithms
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Feature Selection
6. Model Training
7. Model Evaluation
8. Car Price Prediction
